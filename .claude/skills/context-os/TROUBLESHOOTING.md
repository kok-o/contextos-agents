# ContextOS troubleshooting

- Stale projection: inspect edits in core/project sources, compile, export, and
  verify export --check. Do not hand-edit generated artifacts.
- Missing skill: inspect installed manifests and resolver warnings; install only
  the required catalog skill through supported tooling.
- Budget overflow: preserve mandatory safety guidance and reduce irrelevant
  context; the budget is soft and entrypoint-only.
- Wrong risk or selection: supply relevant paths, inspect the actual operation,
  and report a reproducible routing case. A resolver label is not an authority.
- Missing graph command: use resolve --json for workspace package evidence;
  inspect source callers separately for symbol-level impact.
