# ContextOS Benchmark Suite

Comprehensive, reproducible benchmarking tools for evaluating code generated by LLMs with and without ContextOS authoritative skills.

---

## Overview

The ContextOS benchmark suite evaluates how architectural skills, design principles, and guardrails influence code correctness, security, state machine invariants, and runtime behavior.

The suite provides two complementary evaluation mechanisms:

1. **Static AST Analysis Benchmark (`npm run benchmark`)**:
   - Fast, deterministic evaluation of code structure, imports, type definitions, and rule compliance.
   - Zero external execution risk, ideal for rapid CI testing.

2. **Execution-Backed Runtime Sandbox Benchmark (`npm run benchmark:runtime`)**:
   - Compiles TypeScript via native Node.js AST type stripping (`node:module.stripTypeScriptTypes`).
   - Executes generated code in an isolated Node.js V8 context (`node:vm`).
   - Verifies concrete assertions (`node:assert`) against running code, testing cryptographic functions, rate limits, state-machine transitions, and error handling.

## Quick Start

### 1. Static Benchmark

```bash
# Run deterministic mock benchmark
npm run benchmark

# Run live benchmark against OpenAI
npm run benchmark:live -- --provider openai --model gpt-4o

# Run live benchmark against Google Gemini
npm run benchmark:live -- --provider gemini --model gemini-2.5-flash

# Run live benchmark against Anthropic Claude
npm run benchmark:live -- --provider anthropic --model claude-3-7-sonnet-20250219
```

### 2. Execution-Backed Runtime Sandbox Benchmark

```bash
# OpenRouter (Google Gemini 3.8 Flash via Flex Tier)
node benchmarks/run-runtime-benchmark.js \
  --base-url "https://openrouter.ai/api/v1" \
  --api-key "sk-or-v1-..." \
  --model "google/gemini-3.8-flash" \
  --open

# AgentRouter (GPT-5.6-sol)
node benchmarks/run-runtime-benchmark.js \
  --base-url "https://agentrouter.org/v1" \
  --api-key "sk-..." \
  --model "gpt-5.6-sol" \
  --open

# Run a single target scenario
npm run benchmark:runtime -- \
  --base-url "https://agentrouter.org/v1" \
  --api-key "sk-..." \
  --model "gpt-5.6-sol" \
  --task auth-security
```

## CLI Options

| Flag | Type | Description | Default |
|:---|:---:|:---|:---|
| `--provider` | string | LLM provider: `openai`, `gemini`, `anthropic`, `openai-compatible` | auto-detected |
| `--model` | string | Model identifier (e.g. `gpt-5.6-sol`, `google/gemini-3.8-flash`) | required |
| `--api-key`, `--key` | string | API Key (or use environment variables) | env var |
| `--base-url` | string | Base URL for custom or OpenAI-compatible gateways | gateway default |
| `--task` | string | Specific scenario ID (`all`, `auth-security`, `ddd-order-invariants`, `resilient-api-client`) | `all` |
| `--max-tokens` | number | Maximum tokens requested for generation | `4096` |
| `--output` | string | Output directory for reports | `benchmarks/results` |
| `--open` | boolean | Automatically open the generated HTML dashboard in browser | `false` |
| `--no-html` | boolean | Skip HTML report generation (output JSON and MD only) | `false` |

## Runtime Scenarios & Technical Invariants

### 1. Enterprise Auth & Security Token Service (`auth-security`)
- **Skills:** `security`, `typescript`, `engineering-workflow`
- **Tests:**
  - `timing-safe-comparison`: Uses constant-time hash comparison (`crypto.timingSafeEqual`) to prevent side-channel timing attacks.
  - `constant-time-token-signing`: Generates tamper-proof HMAC tokens with bounded expiration (`exp - iat <= 15m`).
  - `brute-force-rate-limiting`: Enforces account/IP lockout after repeated failed attempts and provides reset mechanics.
  - `no-secret-leakage-in-exceptions`: Error messages and stack traces never leak cleartext secrets or database credentials.
  - `input-sanitization-guard`: Strictly rejects empty passwords, malformed emails, and invalid input payloads.

### 2. DDD Order Aggregate Root & Money Value Object (`ddd-order-invariants`)
- **Skills:** `ddd`, `system-design`, `typescript`
- **Tests:**
  - `money-value-object-invariants`: Enforces immutability on `Money` instances (`m1.add(m2) !== m1`), currency mismatch detection, and negative amount rejection.
  - `order-state-invariants`: Validates state-machine transitions (`PENDING` → `PAID` → `SHIPPED`), enforces positive item quantities, and blocks modifications once paid.
  - `domain-events-emission`: Aggregate records domain events (`OrderCreated`, `OrderPaid`) in an internal event queue for downstream dispatch.
  - `repository-interface-decoupling`: Domain logic strictly decoupled from ORMs (no Prisma/TypeORM/HTTP imports).

### 3. Type-Safe Resilient API Client with Circuit Breaker (`resilient-api-client`)
- **Skills:** `typescript`, `system-design`, `performance`
- **Tests:**
  - `timeout-abort-handling`: Implements client-side request cancellation via `AbortController` and signals.
  - `circuit-breaker-transitions`: Three-state circuit breaker (`CLOSED` → `OPEN` → `HALF_OPEN`) tracking failure thresholds and reset cooldowns.
  - `structured-error-taxonomy`: Custom typed error classes without credential leakage in query parameters or headers.
