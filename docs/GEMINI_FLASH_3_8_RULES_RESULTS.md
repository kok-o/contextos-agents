# Результаты уточнения правил для Gemini 3.8 Flash

## Что изменено

Реализованы точечные уточнения из [плана](GEMINI_FLASH_3_8_RULES_PLAN.md), без изменения runtime, MCP, адаптеров и числа skills.

| Источник | Изменение |
| --- | --- |
| `.agents/core/skills/engineering-workflow/SKILL.md` | Явная граница между обсуждением и реализацией; план не завершает запрос на код; конкретные и безопасные условия остановки |
| `.agents/core/skills/engineering-workflow/references/workflow.md` | Утверждения о завершении опираются на наблюдаемые изменения и проверки, а не намерения или напечатанный вызов инструмента |
| `.agents/core/skills/gemini-precision/SKILL.md` | Проверка точного состояния после неоднозначной записи, запрет слепого повтора, смена подхода при повторной ошибке, явное обозначение непроверенного API |
| `.agents/core/skills/gemini-precision/EXAMPLES.md` и `TROUBLESHOOTING.md` | Короткие примеры и процедуры восстановления, согласованные с entrypoint |
| `.agents/core/skills/ponytail-mindset/SKILL.md` | Минимализм не сокращает требования; необходимые подключения и конфигурация входят в завершённое изменение |
| `GEMINI.md` | Краткое отражение контракта; основные требования остаются в экспортируемых канонических skills |

Существующие требования к безопасности, регрессионным проверкам, запрету заглушек и сверке diff сохранены, без создания ещё одного обязательного процесса. Управляемые проекции и registry обновлены штатной сборкой. Поскольку уточнялись общие skills, их проекции обновились и для других адаптеров; их реализация не менялась.

### Ограничение среды Node 26

Первый полный запуск на Node 26.7.0 дал 667 успешных тестов и 10 ошибок benchmark-подсистемы: используемый ею TypeScript transform mode не поддерживается этим runtime. На чистой исходной ревизии в отдельном detached worktree воспроизведены те же десять упавших тестов: 21 прошёл, 10 упали в соответствующей выборке из 31 теста. Сопоставлены идентичности ошибок, а не только суммы.

Benchmark-код не менялся. Полный успешный запуск выполнен с уже установленным Node 24.19.0. Это не исправляет совместимость benchmark-подсистемы с Node 26: если текущая оболочка выбирает Node 26, для воспроизведения зелёного полного набора нужно выбрать Node 24. Временный baseline-worktree удалён без изменения основной рабочей копии.

## Независимый review

Read-only review не обнаружил блокирующих проблем безопасности или логики. Проверены 40 файлов snapshot, полные канонические документы и новые артефакты, а также соответствие изменённых проекций реальному renderer и compiled metadata. После review родительский агент повторно сверил все 40 SHA-256 и размеры: расхождений нет.

Reviewer отдельно выполнил три уже существующих/добавленных core-skill теста и самопроверки семи oracle fixtures. Они не прибавляются к 677 как дополнительные уникальные тесты. Необязательное предложение усилить проверку полного inventory baseline/scenario pack оставлено на последующую итерацию; текущий комплект проверен полностью.

Этот отчёт добавлен после review и отдельно проверен Markdown lint; утверждение о review 40 файлов не включает его.
