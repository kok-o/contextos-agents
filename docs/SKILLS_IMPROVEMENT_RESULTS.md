# Результат улучшения навыков ContextOS

Дата: 28 октября 2026. Область: семь core и 44 записи каталога.
Работа выполнена локально поверх сохранённого исходного состояния.

## Что изменено

Рассмотрены все 51 записи: 35 переработаны, 16 сохранены после проверки.
Решения и границы проверок для каждой записи находятся в
[матрице](product/skill-inventory.json); порядок работы — в
[плане](SKILLS_IMPROVEMENT_PLAN.md).

- Уточнены назначение, условия применения и ответственность навыков. Пять
  совместимых имён сохраняют canonical redirects, без больших копий инструкций.
- Убраны универсальные требования Redis, TypeScript, DDD, TDD и масштабной
  архитектуры там, где задаче они не нужны. Активный навык каталога может
  компилироваться и явно выбираться отдельно от соседних инструкций.
- Стилевые пакеты оставлены вариантами для соответствующего brief. Продуктовые
  сценарии, визуальная композиция, review, доступность, motion и диагностика
  производительности разделены по ответственности. Запреты на шрифты и цвета
  удалены также из UI-шаблона.
- Исправлены примеры FastAPI и повторяемого React-поля; шаблоны документов
  различают предложение, существующее состояние и подтверждённое выполнение.
- Graphify и orchestration описывают доступные средства и ограничения, без
  обещаний автоматического анализа, нулевой стоимости контекста или отсутствия
  конфликтов. Навыки сохраняют текущую авторизацию пользователя.
- Descriptions registry/index согласованы с canonical SKILL.md. Ресурсы
  перечислены в manifests; новые восемь frontend-навыков и их источники сохранены.

## Исправленные дефекты

| Дефект | Новое поведение | Воспроизведение |
| --- | --- | --- |
| Prefix-only проверка пути допускала соседний каталог | Пример проверяет realpath и границу через path.relative, отклоняет внешние links | Исходный Markdown-блок исполняется на разрешённых/запрещённых путях; проверка не является race-safe open или авторизацией |
| Vercel collector безусловно выдавал фиксированные числа | Требуется импорт JSON или явный demo; live telemetry не реализована | Без режима — ненулевой exit, demo помечен synthetic, импорт сохраняет измерения и проверяет projectId |
| Merge терял synthetic и превращал отсутствие метрик в нули | Признак demo сохраняется, неизмеренные маршруты остаются без метрик | Merge → gate отклоняет demo без явного allow-demo |
| Gate предлагал кеширование для no-store без публичной политики | Нужна явная cacheable-политика; приватные, уже кешируемые и workflow-маршруты исключены из соответствующих кандидатов | Отдельные положительные/отрицательные fixture cases |
| Ошибки JSON могли повторять содержимое входа | Диагностика парсинга ограничена | Неверный JSON с маркером секрета не попадает в stdout/stderr |
| Любой Python-файл/manifest подразумевал FastAPI | Общие Python-файлы не являются сигналом FastAPI | Отрицательные EN/RU задачи и положительная явная FastAPI-задача |

Скрипт gate выдаёт кандидатов для исследования; пометка supplied не удостоверяет
источник наблюдений. Текстовый scanner не доказывает реальные маршруты, runtime
или стоимость. Эти границы явно указаны в навыке.

[catalog-quality.md](product/catalog-quality.md).
