# Archived release records

These documents describe how earlier releases were prepared and verified. They
are kept because the release tooling and changelog refer to them, and because
they show what was and was not measured at the time. They are not instructions:
commands, layouts and limits described here may no longer match the current
version. For current behavior, read the [README](../../README.md),
[guide](../../GUIDE.md) and [compatibility matrix](../ADAPTER_COMPATIBILITY.md).
